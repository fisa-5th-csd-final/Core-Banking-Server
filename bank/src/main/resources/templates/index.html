Core Bank 디지털

코어뱅킹 서비스에 오신 것을 환영합니다

계좌 개설, 대출, 송금, 카드결제까지 하나의 플랫폼에서 안전하게 이용하세요. 신규 고객이라면 회원가입 후 로그인하여 서비스를 시작할 수 있습니다.

회원가입 로그인 API 문서

간편 로그인

커스텀 로그인 페이지를 통해 안전하게 인증하고, JWT 기반으로 보호된 API에 접근합니다.

통합 회원가입

생년월일, 직업, 연봉 등 필수 정보를 입력하면 바로 계정이 생성됩니다. 입력 연봉은 자동으로 천 단위 콤마를 지원합니다.

API 기반 코어

/api/users, /api/accounts, /api/loans 등 REST 엔드포인트로 코어뱅킹 기능을 제공합니다. Swagger 문서에서 바로 확인하세요.
